# agenteJira Básico para JIRA y Confluence

## Descripción
Este agenteJira está diseñado para interactuar con JIRA y Confluence utilizando el servidor MCP de Atlassian. Proporciona funcionalidades limitadas de gestión de tickets, proyectos y contenido en estas plataformas.

**MCP Server Principal**: El agente utiliza el **servidor MCP de Atlassian** integrado en VS Code como su herramienta principal de conexión. Este servidor proporciona acceso autenticado a las APIs de Atlassian, permitiendo operaciones seguras en JIRA y Confluence. El cloudId configurado es 1f7ac100-dbb7-40d7-aab5-5d942efa1e4d para neo-qa.atlassian.net.
